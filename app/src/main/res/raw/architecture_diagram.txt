Theme.kt (UI Theme)
    ├─→ extends: Color.kt

    └─→ extends: Shapes.kt

## Export & Watermark Flow

User long-presses Asset
         ↓
   VaultActionMenu appears
         ↓
   User taps "EXPORT / SHARE"
         ↓
   ExportDispatcher opens
   (UPDATED: Single file selection dropdown)
         │
         ├─ User selects file from dropdown
         │  (Background PNG | Transparent PNG | .pntr)
         │
         ├─ useWatermark = FALSE (default)
         │   ├─ User taps SAVE → onExportToDevice(asset, [selectedType], false)
         │   └─ User taps SHARE → onShareSheet(asset, [selectedType], false)
         │
         └─ useWatermark = TRUE
             ├─ Shows warning: "⚠ Watermark will be applied to the selected file"
             ├─ User taps SAVE → onLaunchWatermarkStudio(asset, [selectedType], "device")
             │                    ↓
             │            Export dialog dismissed
             │                    ↓
             │            WatermarkStudioDialog opens
             │            (previews CORRECT file based on selectedType)
             │                    ↓
             │            User adjusts watermark
             │            (opacity & scale sliders)
             │                    ↓
             │            User drags watermark on preview
             │                    ↓
             │            User taps CHECK (✓)
             │                    ↓
             │            onFinalize(opacity, scale, offset)
             │                    ↓
             │            File export happens with watermark applied
             │
             └─ User taps SHARE → onLaunchWatermarkStudio(asset, [selectedType], "share")
                                   ↓
                           Same flow as above
                                   ↓
                           Share menu appears with watermarked file

Key Changes:
  ✓ ExportDispatcher: Changed from checkboxes to single dropdown
  ✓ Only one file can be exported per action (no multiple selections)
  ✓ Dropdown shows only available files for asset
  ✓ Warning note appears when watermark is enabled
  ✓ WatermarkStudioDialog now receives selectedFileType parameter
  ✓ Studio previews the CORRECT file (background/transparent/.pntr)
  ✓ Fixes issue where transparent files only showed watermark

## Watermark Studio Integration

ExportDispatcher Features:
  ✓ useWatermark toggle (default: OFF)
  ✓ Checkbox: "Apply Watermark" + "PNG files only" note
  ✓ SAVE button → Export or launch studio
  ✓ SHARE button → Share or launch studio

WatermarkStudioDialog Features:
  ✓ Full-screen asset preview (background/main preview/transparent)
  ✓ Draggable watermark layer
  ✓ Opacity slider (0-100%)
  ✓ Scale slider (0-100%)
  ✓ Settings persisted via WatermarkPreferenceManager
  ✓ Close button (✕) - cancels export
  ✓ Check button (✓) - finalizes and proceeds to export/share

LibraryDialogDispatcher Watermark Flow:
  1. Export dialog opened with useWatermark = FALSE (default)
  2. User toggles watermark ON and taps SAVE/SHARE
  3. ExportDispatcher calls onLaunchWatermarkStudio(asset, types, action)
  4. Export dialog dismissed
  5. WatermarkStudioDialog opens with asset preview
  6. User adjusts opacity, scale, and position
  7. User taps CHECK (✓)
  8. onFinalize callback → stores watermark settings
  9. Pending action ("device" or "share") executes
  10. TODO: Apply watermark to selected PNG files
  11. File picker (export) or share menu (share) appears
  12. Dialog closes, state cleaned up

State Management:
  - studioLaunchedAsset: Current asset in studio
  - pendingExportAction: "device" or "share"
  - pendingExportTypes: Selected file types to export
  - WatermarkPreferenceManager: Persists opacity, scale, last used settings
